# Diabetic Retinopathy Detection using AI

Deep learning project for automated diabetic retinopathy detection using retinal fundus images. This project compares CNN, VGG19, and ResNet50 architectures using the APTOS 2019 dataset for early-stage disease classification.

## Technologies
- Python
- TensorFlow / Keras
- OpenCV
- Google Colab
- NumPy / Pandas

## Features
- Retinal image preprocessing
- Data augmentation
- CNN-based image classification
- Transfer learning using ResNet50 and VGG19
- Performance evaluation and comparison

## Results
The project achieved high classification accuracy in detecting diabetic retinopathy severity using deep learning models.

## Dataset
APTOS 2019 Blindness Detection Dataset
